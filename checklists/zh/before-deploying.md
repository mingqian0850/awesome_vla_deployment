# 部署前检查表

[首页](../../README.md) · [English](../before-deploying.md)

## 配置与接口

- [ ] 明确实际加载的检查点、适配器、处理器统计量及最终配置。
- [ ] 关节顺序、单位、动作模式、控制频率和夹爪约定匹配控制器。
- [ ] 相机名称、视角与标定匹配记录的配置。
- [ ] 分别记录预测步数与实际执行步数。
- [ ] 启用执行器前，已检查离线生成的指令。

## 防护与时序

- [ ] 针对此配置核实硬件、控制器防护功能与人员进入流程。
- [ ] 位置、速度、加速度及工作区限制匹配硬件和任务。
- [ ] 有适当的独立组件检测心跳丢失或策略故障。
- [ ] 观测陈旧、推理超时、队列为空均有经过验证的响应。
- [ ] 停止与重启条件考虑重力、负载、接触和意外运动。
- [ ] 实测端到端延迟、抖动和剩余指令缓冲时间。
- [ ] 相邻动作块的衔接没有未经验证的跳变。
- [ ] 人工接管有明确控制权，并在受控条件下演练。

## 评测与记录

- [ ] 报告任务成功率、试验数量、初始条件与不确定性。
- [ ] 单独记录目标错误、人工介入和部分完成情况。
- [ ] 日志记录时间戳、已发送指令及防护事件。
- [ ] 恢复行为具有前置条件，并针对实际任务测试。
- [ ] 分别检查模型权重、代码、数据和第三方资产的许可。
- [ ] 版本化部署记录能识别复现配置所需的全部资料。

使用[部署配置模板](../../templates/deployment-manifest.yaml)。空字段需要填写实测值与经过验证的配置。复核[运行防护](../../docs/zh/43-safety.md)与[时序](../../docs/zh/41-real-time-inference.md)。
