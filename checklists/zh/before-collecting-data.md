# 采集前检查表

[首页](../../README.md) · [English](../before-collecting-data.md)

## 任务与覆盖

- [ ] 已定义任务指令、episode 终点与成功失败标准。
- [ ] 覆盖计划记录物体、位姿、光照和初始状态的变化。
- [ ] 多阶段任务有足够的可观测状态、历史或受支持的阶段标签来识别进度。
- [ ] 评测 episode 或条件与训练数据分离。
- [ ] 已定义复位流程与人工介入标签。

## 数据约定

- [ ] 写清状态动作维度、关节顺序、单位和坐标系。
- [ ] 确认绝对 / 增量 / 速度动作及夹爪开闭方向。
- [ ] 记录相机名称、视角、内外参与图像格式。
- [ ] 记录采样和控制频率，明确重采样与同步方式。
- [ ] 标定文件及版本与本次采集一起保存。
- [ ] 记录归一化方式和统计量来源；缺少特征时明确报错。

## 录制质量

- [ ] 检查 episode 起止处非预期的空闲段。
- [ ] 检查丢帧、时间戳跳变及观测动作对齐。
- [ ] 检查图像曝光、对焦与视角一致性。
- [ ] 标记失败或中断的 episode，避免默默混入成功数据。
- [ ] 在环境支持回放时，回放示教并核实任务结果。
- [ ] 检查跨 episode 边界的末尾填充与目标掩码。

## 扩大采集前先试运行

- [ ] 记录 episode 数量、时长、不同条件及结果分布。
- [ ] 大规模采集前，先用试采集数据训练并评测。
- [ ] 检查逐维统计量与失效的状态通道。
- [ ] 分别检查模型、数据集与第三方资产的许可条款。

使用[采集日志](../../templates/collection-log.csv)。可选诊断：`python scripts/diag_dataset.py /path/to/lerobot_dataset`，需要 NumPy 和 PyArrow。继续阅读[数据与训练](../../docs/zh/01-data-and-training.md)。
