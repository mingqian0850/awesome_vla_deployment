# 第一步：工业与学术研究使用什么数据？

[首页](../../README.md) · [English](../02-data-sources.md)

核对日期：2026-10-20。先确定需要学习的能力，再确定采集信号。第一视角描述相机位置，不保证存在机器人动作标签。下面是可核对的代表性路线，不是行业份额统计，也不要求先购买采集设备。

## 五类数据与用途

| 类型与公开入口 | 可以观察或获得什么 | 不能直接推出什么 |
| --- | --- | --- |
| [Ego-Exo4D](https://docs.ego-exo4d-data.org/)：人类多视角技能数据 | 同步第一／第三视角及步骤、语言、姿态等标注；具体覆盖依子集 | 没有目标机器人的控制命令，不能直接当机器人 action |
| [EgoMimic](https://github.com/SimarKareer/EgoMimic)：人类与机器人联合学习 | Aria 人类数据与机器人遥操作数据的处理和训练入口 | 普通视频无需追踪、对齐就能训练任意机器人 |
| [UMI](https://umi-gripper.github.io/)：手持夹具示教 | 相机图像、工具轨迹与夹爪开合；缩小采集和执行接口差异 | 任意多指手或全身运动都能直接迁移 |
| [AgiBot World](https://github.com/OpenDriveLab/AgiBot-World)：机器人操作数据 | 按发布版本读取视觉、状态、动作与任务信息 | 公开数据就是 G2 某工厂的部署数据，或自带完整双足行走监督 |
| [GR-1 仿真遥操作数据](https://huggingface.co/datasets/nvidia/PhysicalAI-Robotics-GR00T-Teleop-Sim) | 仿真机器人示教，页面可查看 state、action、timestamp 等字段 | 仿真成功证明产线可用；该数据卡标注 CC-BY-NC-4.0 |

这些路线可以组合。研究中“无目标机器人示教”的结果必须按具体方法、输入、任务和评测理解；不能推广成“任何 ego 视频都能直接部署”。检查数据、代码和权重各自的许可，版本间不要混用统计量或 schema。

## 工业案例公开到了哪里

[Mercedes-Benz × Apollo](https://group.mercedes-benz.com/company/production/production-network/mbdfc-humanoid-robots.html) 披露生产员工通过遥操作和 AR 传授任务；未公开完整训练集。[Atlas / TRI](https://bostondynamics.com/blog/large-behavior-models-atlas-find-new-footing/) 披露 VR 遥操作和多平台训练数据，这是平台研究说明，不能自动归属到某个量产工位。

“企业用了遥操作”不能推出相机型号、动作维数、采集小时数或人类／机器人数据配比。未经披露的字段保持未知。

## 一条 episode 应当读懂什么

以下是建议的检查结构，不是任一上游数据集的精确 schema。episode 是一次有边界的尝试，可能成功、失败或被中断。

| 字段组 | 必须回答的问题 |
| --- | --- |
| 任务与身份 | task、episode_id、采集场次、对象／SKU；起止和复位如何定义？ |
| 观测 | 相机名称、图像大小、是否有深度；遮挡和缺帧怎么标记？ |
| state | 实测关节／末端状态，还是估计姿态？关节顺序是什么？ |
| action | 命令、未来状态标签还是重定向参考？绝对／增量／速度？单位、坐标和控制模式是什么？ |
| 时间与标定 | 采样时间和接收时间是否混淆？相机、状态和命令延迟怎样对齐？ |
| 工艺结果 | 动作完成、质量合格、设备测试结束、人工接管是否分别记录？ |
| 谱系与分割 | 原始数据、处理版本、标定、训练／验证分组能否追溯？ |

把测量、估计、重定向参考、发出的命令和执行反馈分开。未知力信号不是零；下一帧 state 也不一定等于本帧 action。先读采集器和控制器定义，再决定训练标签。

## 按任务补充信号

- 固定位取放：左右臂、夹爪、手眼／工具标定、工件和工装状态。
- 接触装配：根据工艺增加力／力矩或触觉、接触事件和独立质量判据；仅有视觉轨迹无法保证插接质量。
- 移动到位再操作：增加底座位姿、站位／停车误差和到位条件。
- 行走与操作耦合：进一步检查全身运动、足底接触、负载和控制器跟踪。人形外观并不证明数据覆盖这些量。

这是一份需求清单，不表示所有任务都需要所有传感器。

## 8GB 笔记本上的第一份作业

1. 先打开 AgiBot World 的数据说明／可视化入口，或 GR-1 的网页数据查看器；选择一种格式和一个 episode，不下载完整数据集。
2. 为 image、state、action、timestamp 各写一行：来源、形状、单位、坐标、采样频率。未查明的填 unknown。
3. 画一个抓取到放置的时间段，说明动作命令与状态反馈是否存在延迟，以及完成判据来自哪里。
4. 对照 EgoMimic 的人类数据，列出缺少的机器人字段；再看 UMI 如何改变采集接口。
5. 输出一页字段说明和问题清单。无需权重、训练或真实机器人；下载前检查分片大小和访问条件。
